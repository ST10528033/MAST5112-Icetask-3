ICE Task 3: Album Collection & Debugging

A React Native mobile application built with Expo and TypeScript for managing a personal favorite music album collection. This repository contains the fully debugged and corrected implementation as part of ICE Task 3.   
PNG

Project Overview

The primary goal of this task was to investigate, identify, and correct intentional errors across the provided starter code (App.tsx) while maintaining the original application architecture and functionality.   
PNG

Core Functionality

Album Entry & Form: Capture detailed album records including Title, Artist, Release Year, Genre, and Rating (1–5).   

Form Validation: Comprehensive pre-submission checks to ensure valid data entry.   

Collection Management: Add new albums to state without overwriting existing entries and remove items dynamically.   

Dynamic Rendering: Efficiently display the list of saved albums using React Native FlatList.   

 Built With
Framework: React Native (Expo Blank TypeScript Template)   

Language: TypeScript   

UI Components: @expo/ui (Picker component)
